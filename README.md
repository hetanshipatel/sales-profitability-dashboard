# Sales & Profitability Dashboard

## Project Overview
This project uses Power BI to explore sales performance, profitability, product categories and regional trends through an interactive dashboard.

## Business Questions
- How do sales change over time?
- Which product sub-categories generate the most and least profit?
- How do sales compare across regions and product categories?
- How can users explore performance using date, region and category filters?

## Dashboard Features
- **KPI cards:** Total Sales, Total Profit, Total Orders, Profit Margin, Total Quantity and Average Order Value.
- **Monthly Sales Trend:** Tracks sales over time.
- **Profit by Sub-Category:** Compares profit across product sub-categories.
- **Sales by Region and Category:** Compares category sales across regions.
- **Interactive filters:** Region, category and order date.
